# Match Analytics: предматчевая оценка вероятностей исхода футбольного матча

Учебный командный проект курса «Аналитик данных» (Changellenge Education), 2026.
Инструменты: **Python** (pandas, scipy, scikit-learn), **Tableau**.

## Задача

Инвестор, который увлекается футболом, хочет получить дашборд для решения о ставке на конкретный матч. Нужно было:
1. собрать данные из базы матчей в одну таблицу для анализа;
2. статистически выбрать 2–3 ключевые предматчевые характеристики, которые связаны с исходом;
3. сделать дашборд: пользователь выбирает две команды и видит вероятности исходов.

Данные: [European Soccer Database](https://www.kaggle.com/datasets/hugomathien/soccer) (Kaggle): 25 979 матчей 11 европейских лиг, составы, рейтинги игроков и команд из FIFA.

## Результат

- **Две ключевые характеристики.** Первая — сила стартового состава, то есть разница средних рейтингов игроков (ε² ≈ 0,129). Вторая — текущая форма, средняя разница голов за последние 5 матчей (ε² ≈ 0,059). Эффект в ожидаемом направлении подтверждается во всех 11 лигах. Стиль игры связан с исходом слабо (ε² ≤ 0,013), поэтому в дашборде он только справочный и в модель не входит.
- **Модель.** Мультиномиальная логистическая регрессия на признаках Δ сила состава + Δ форма + лига. На выходе вероятности трёх исходов: победа хозяев, ничья, победа гостей.
- **Качество на отложенном сезоне 2015/16** (3 326 матчей, в обучении и калибровке не участвовал):

  | Метрика | Baseline (частоты классов) | Модель |
  |---|---|---|
  | Accuracy | 43,9% | **50,3%** (+6,4 п.п.) |
  | Log Loss | 1,073 | **1,001** |

- **[Дашборд в Tableau Public](https://public.tableau.com/app/profile/stanislav.zhikharev/viz/Tableau_Team3_v5/Dashboard).** Выбор лиги и команд, вероятности исходов, сравнение силы составов и формы, справочный профиль стиля игры.

## Как решали

1. **Подготовка данных** (`1_football_data_preparation.ipynb`). Проверка качества: в данных обнаружен неполный сезон Belgium Jupiler League 2013/14, всего 12 матчей, он исключён. Аналитическое окно с 2010/11 даёт 19 411 матчей. Таблица переведена в длинный формат «команда × матч», признаки формы считаются через `shift(1)` + rolling, рейтинги берутся по as-of join на дату до матча. Проверено, что ни один признак не использует информацию после начала матча.
2. **Статистический отбор** (`2_football_statistical_analysis.ipynb`). Тест Kruskal–Wallis и размер эффекта ε² для каждого кандидата: при 19 тыс. матчей p-value почти всегда около нуля, поэтому решение принималось по размеру эффекта. Дальше проверка устойчивости по лигам и корреляции Спирмена между признаками формы, чтобы убрать дубли.
3. **Модель и валидация.** Разбиение по времени: train 2010/11–2013/14 (12 760 матчей), validation 2014/15 (3 325), test 2015/16 (3 326). Предобработка обучается только на train.
4. **Выгрузка для Tableau.** Отдельные таблицы с прогнозами по матчам, текущим состоянием команд и параметрами модели.

### Как запустить

Второй ноутбук работает на CSV из репозитория. Для первого нужна исходная база: скачайте её с Kaggle, выгрузите таблицы `matches`, `lineups`, `player_attributes`, `team_attributes` в CSV и положите в `original_db + export/csv_export/`. Ноутбуки лежат в корне репозитория: пути в них заданы от текущей папки.

```bash
pip install pandas numpy scipy scikit-learn matplotlib
```
